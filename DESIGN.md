# BuyByFit design notes

## Direction

The build uses a **specimen catalogue** composition: individual pieces sit on restrained material-colour fields so visitors can compare their silhouette and room-fit facts at a glance. On Discover, a free-form room brief is the live element; only after it is submitted does the mock catalogue appear.

## Adaptations

The dealt pastel palette was replaced with the brief's warm paper, oat, sage, and timber palette; the dealt two-serif system was replaced with a high-contrast system serif display face plus a quiet sans-serif UI face. These changes keep the Scandinavian, premium marketplace request intact.

Photo fields use a deliberate pair of soft, asymmetrical corner radii so the generated imagery sits inside the material palette rather than reading as hard rectangular tiles.

## Tokens

- Paper: `#F7F5F0`
- Oat field: `#E7DED0`
- Timber accent: `#8D7258`
- Sage field: `#A1A999`
- Ink: `#292B28`
- Surface: `#FFFFFF`

## Image policy

`public/images/` contains generated, fictional demonstration imagery. It establishes a visual placeholder system only and must be replaced with licensed product photography before a real catalogue launch.
